# Build the Lever

**Apply when:** work is repeated, broad, error-prone, or uncertain enough that a reusable tool can perform or prove it.

Build the smallest script, codemod, generator, fixture, checker, or driving route that turns the work into a deterministic operation. The lever should be the artifact a reviewer can run, not a private convenience whose output must be trusted.

Build it before the bulk work when every later unit benefits. Keep it only when repetition, risk, or future maintenance repays its cost; otherwise use a throwaway script and remove it during cleanup.

A lever does not justify automation around a one-line edit. Its value is repeatability, coverage, or stronger evidence.

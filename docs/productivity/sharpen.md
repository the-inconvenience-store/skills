## What it does

`sharpen` makes a task brief **deeper, not bigger**. It names better starting material, a concrete method, and evidence that would show the result is right.

## When to reach for it

You invoke this by typing `/sharpen`; it does not run on its own. Use it when you know the goal but the draft leaves too much to guess about how to establish a good result.

## Common questions

**Will it do the task or add deliverables?** No. It returns a prompt you can send. It keeps the original scope and leaves preference decisions to you.

## Where it fits

Use it before sending a task prompt. [Reframe](https://aihero.dev/skills-reframe) helps name an unclear problem first. [Ask Inconvenient](https://aihero.dev/skills-ask-inconvenient) helps choose.

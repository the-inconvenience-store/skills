# Run checkpoint

Update the agreed plan or checkpoint location after a verified unit, when evidence no longer matches the current artifact, or before a pause. If no durable artifact was requested, put the checkpoint in the reply. If `/show-me-your-work` is already active, link to its trail instead of copying the decisions.

Record enough for a fresh reader to resume without guessing:

- Goal, scope, exit condition, remaining budget, and stopped versus active work.
- Current branch or worktree, base and head when relevant, and outstanding local edits or delegated work.
- Last completed unit and its evidence: command or interaction, observed outcome, and artifact location. Mark any result invalidated by a later edit or head change.
- Next action, blockers, pending decisions, and which actions need authorization.
